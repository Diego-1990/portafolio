Imperial Parfums

Tienda premium de perfumes con catalogo, autenticacion JWT, roles, carrito persistente y paneles para vendedor y administrador.

Resumen

Imperial Parfums simula una plataforma ecommerce real para venta de perfumes de lujo. El proyecto separa frontend y backend, protege rutas por roles y conecta el carrito, catalogo y cuenta del usuario con una API REST.

Funciones principales

  • Registro, login, JWT y refresh tokens.
  • Roles USER, SELLER y ADMIN.
  • Catalogo publico con busqueda y filtros.
  • Carrito conectado al backend e historial de pedidos.
  • Panel vendedor para productos y panel admin para usuarios y ordenes.
